# CMX PRO BIM — versões publicadas

Plugin HVAC para Autodesk Revit 2024, 2025, 2026 (2026.5+) e 2027.

Este repositório guarda só os instaladores e as notas de cada versão. O uso do plugin exige uma
licença emitida pela CMX PRO.

## Instalar

1. Baixe o `CMXPro-BIM-Setup-<versão>.exe` da [última versão](../../releases/latest).
2. Feche o Revit e execute o instalador.
3. No Revit, painel **CMX → Licença**, cole a sua chave de licença.

Depois disso o CMX PRO BIM se atualiza sozinho: ao abrir o Revit ele verifica se há versão nova,
baixa em segundo plano, confere a assinatura do instalador e instala quando você fechar o Revit.
